# 🐷 Bad Piggies — Dota 2 Companion Widget (C++)

Интерактивный виджет-компаньон для **Dota 2** на чистом **C++** (Win32 + GDI+).
Свинка из Bad Piggies сидит в правом нижнем углу экрана, спокойно дышит, а когда ты делаешь килл в Доте — радостно прыгает с облачком текста: **«Молодец! Ты сделал килл!»** и звуковым эффектом!

А если у тебя **мало здоровья ($\le 25\%$)** — весь экран начинает пульсировать **тревожной красной виньеткой**, свинка паникует и кричит: **«МАЛО ХП! ЖМИ БКБ / ТП!»** с биением сердца!

---

## ✨ Возможности

- **7 вариантов свинок на выбор**:
  - **Вид 1**: Король свиней (с короной) 👑
  - **Вид 2**: 3D Свинка из фильма
  - **Вид 3**: Классическая круглая свинка
  - **Вид 4**: Крутая свинка в пиксельных очках (Thug Life) 😎
  - **Вид 5**: Свинка в красной кепке
  - **Вид 6**: Свинка с веснушками
  - **Вид 7**: Улыбающаяся милая свинка
- **🩸 Пульсирующая красная виньетка при мало ХП**:
  - Когда здоровье героя опускается ниже 25%, по краям экрана пульсирует кроваво-красная виньетка (центр экрана остается прозрачным, чтобы видеть драку).
  - Звук тревожного биения сердца (`low_hp.wav`).
  - Свинка трясется в панике и напоминает прожать БКБ или ТП.
- **Интерактивное окно настроек**:
  - Живое превью выбранной свинки.
  - Настройка размера виджета (Маленький, Средний, Большой).
  - Включение/отключение звуков.
  - Кнопки быстрого тестирования:
    - **«🎯 Тест: Килл! (Прыжок)»**
    - **«💀 Тест: Смерть»**
    - **«🩸 Тест: Мало ХП (Виньетка)»**
- **Официальный Dota 2 GSI (Game State Integration)**:
  - 100% легально, Valve за это **не банит**.
  - Конфиг автоматически прописан в `game/dota/cfg/gamestate_integration/`.
- **Прозрачный оверлей (Click-Through)**:
  - Сквозной клик: мышка кликает сквозь свинку прямо в Доту, окно ничему не мешает в бою.

---

## 🚀 Как запустить

1. Запусти файл `StartWidget.bat` (или `BadPiggiesDotaWidget.exe`).
2. В окне настроек нажми **«🩸 Тест: Мало ХП (Виньетка)»**, чтобы сразу увидеть пульсирующую красную виньетку и реакцию свинки!
3. Нажми кнопку еще раз, чтобы выключить тест.
