НОВОЕ В v6.0 — ЛОКАЛЬНЫЙ ИИ И МЕНЬШАЯ НАГРУЗКА:
- После первой просьбы поговорить Свин бесплатно загружает языковую модель (~563 МБ).
- После загрузки ответы работают локально; запросы диалога не отправляются в облако.
- Для актуальной погоды требуется интернет.
- ИИ использует не больше двух потоков процессора и один запрос одновременно.
- Через 30 секунд тишины модель выгружается из оперативной памяти. При следующем вопросе ей нужно время, чтобы загрузиться снова.
- Во время ответа модель может занимать около 0,8–1,2 ГБ ОЗУ; после выгрузки остаётся только лёгкое голосовое распознавание. Фактическая нагрузка зависит от компьютера.
- В выборе героя Свин получает пики/баны и список разрешённых героев из Dota Game State Integration.

* «Свин, что качать?» -> билд способностей героя.
* «Свин, пошути!» / «Анекдот!» -> более 12 000 дотерских шуток без повторов!
* «Свин, как дела?» -> отчёт по катке и настроению.
* «Свин, включи токсика!» / «Свин, по-братски!» -> голосовая смена характера.

* «Свин, какая погода в Смирных?» -> загружает текущую погоду бесплатно.
* После слова «Свин» можно задать вопрос или продолжить разговор; стиль ответов подстраивается локально.

Нет платных AI API и ключей. Распознавание, команды и память работают локально.
Для погоды требуется интернет: текущие данные загружаются у Open-Meteo только по команде.
Генеративная облачная нейросеть не используется.

🎮 ГОРЯЧИЕ КЛАВИШИ В ИГРЕ:
------------------------------------------------------------------------
* F5 — TikTok Мемы / Поболтать
* F6 — «Что купить?» (проверяет реальный инвентарь и золото)
* F7 — «Что качать?» (порядок прокачки скиллов)
* F8 — Пошути / Дотерский анекдот
* Left Ctrl + ЛКМ — Перемещение свинки мышкой по экрану
* Навести на свинку + Right Shift — Открыть меню настроек прямо в Доте
